# Crisp Proposal Gate 💍✨

> An interactive, high-end digital invitation and proposal portal designed to replace boring notifications with an engaging, romantic, and gated experience. 

Part of the **Crisp Suite** ecosystem—built for modern, aesthetic, and memorable micro-interactions.

---

## 🌟 Key Features

* **3D Envelope Opening Effect:** Features an interactive rose-gold wax seal and smooth CSS 3D folding animations to build anticipation before revealing the main message.
* **Step-by-Step Screening Gate:** Guides users through a multi-step verification process (Name, Passcode/Anniversary Date, Proposal Type, Target Date) before granting access.
* **Light & Dark Mode Support:** Seamlessly toggles between a deep luxury dark theme and a clean, crisp light theme via a floating header button.
* **Interactive Response Flow:** Complete with dynamic VIP passes and response actions (*"Yes, Forever ❤️"* or *"Let's Talk 💬"*).
* **Zero Backend / 100% Static:** Built using pure HTML, CSS, and Vanilla JavaScript. Fast, lightweight, and ready for instant deployment on **GitHub Pages**.

---

## 🚀 Tech Stack

* **Markup & Structure:** HTML5
* **Styling:** CSS3 (Custom Variables, Flexbox, Keyframe Animations, Perspective 3D Transforms)
* **Logic:** Vanilla JavaScript (DOM manipulation, step-state handlers)
* **Hosting:** GitHub Pages
